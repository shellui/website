# Site localization (Eleventy)

English is the default locale at unprefixed URLs (`/`, `/features/`, `/guidelines/`, …). French, German, and Italian mirror the same paths under `/fr/`, `/de/`, and `/it/`.

## Adding or updating a page

1. **English (default)** — Add or edit the page under `src/` as today (for example `src/features/storage/index.njk` or `src/pricing/index.md`).
2. **Locale mirrors** — Add the same relative path under each locale directory:
   - `src/fr/features/storage/index.njk`
   - `src/de/features/storage/index.njk`
   - `src/it/features/storage/index.njk`
3. **Locale cascade** — Each locale folder includes `{lang}.json` (for example `src/fr/fr.json` with `{ "lang": "fr" }`). That sets `lang` for every page in the tree.
4. **Explicit permalinks** — Redirect stubs and special pages (404, `/product/brand-assets/`, legacy feature URLs) declare `permalink:` in front matter. Locale copies must use a prefixed permalink (for example `permalink: /fr/features/chrome/`). Run `node tools/sync-locale-pages.mjs` to copy new English stubs into `src/fr`, `src/de`, and `src/it` (then translate and fix permalinks).
5. **Chrome strings** — Navigation, footer, breadcrumbs, feature hub cards, and shared includes pull from `src/_data/translations/{en,fr,de,it}.js`. Regenerate base bundles with `node tools/build-locale-bundles.mjs`, then edit locale-specific strings.
6. **Guidelines markdown** — English sources stay in `content/guidelines/`. Translated handbooks live in `content/locales/{fr,de,it}/guidelines/*.md` and are copied to `/fr/guidelines/…`, `/de/design.md`, etc. at build time.

## SEO

- `src/_data/eleventyComputed.js` exposes `alternateLanguages`, `htmlLang`, `ogLocale`, and locale-aware `canonical`.
- `src/_includes/layouts/base.njk` emits `hreflang` links for `en`, `fr`, `de`, `it`, and `x-default` (English).
- `/sitemap.xml` lists all locale URLs via the `collections.sitemap` collection.

## Language switcher

`src/_includes/language-switcher.njk` maps the current page to the equivalent URL in each locale using the English path (`englishPath`). If a locale page is missing, Eleventy would not emit that URL; in practice the locale trees are kept in sync.

## Agent contract for `design.md`

`https://shellui.com/design.md` remains the **English** composition authority for agents. Localized design handbooks are published at `/fr/design.md`, `/de/design.md`, and `/it/design.md` for human and locale-aware workflows. `/llms.txt` documents both.

## Do not duplicate

Keep a single copy of: `src/llms.njk`, `src/robots.njk`, `src/sitemap.njk`, and `src/blog/feed.njk` (English-only).
