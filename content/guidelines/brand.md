The Shellui brand kit v1 is the canonical reference for logo usage, color, typography, and social templates. Download the PDF for the full handbook, or grab the asset zip when you need production files.

## Downloads

- [Brand kit v1 (PDF)](/brand-assets/shellui-brand-kit-v1.pdf): 33-page brand handbook
- [Brand assets v1 (ZIP)](/brand-assets/shellui-brand-assets-v1.zip): logos, icons, Open Graph images, social banners, and email signature files

Individual logos and marks for quick use stay on [Brand assets](/brand-assets/).

## Type and UI (site alignment)

The kit matches how shellui.com is built today:

- **Typography**: the website uses the system UI font stack. Logos, Open Graph images, and social templates in the asset zip use Inter.
- **Durations**: write seconds as `30s`, not spelled-out words.
- **Controls**: site chrome uses `rounded-md` corner radius on buttons and inputs.
- **Gold tint**: use flat gold backgrounds in print and social images (Open Graph). The soft honey gold wash is for the website only.
