## 2.0.0 (2026-10-25)

Major reorganization for the website release.

- **Hub**: overview and topic cards for Brand, Foundations, Writing, Interface, and Print
- **Brand**: identity and [Downloads](/guidelines/brand/#downloads) replace the standalone brand assets page (legacy URLs redirect in the browser)
- **Foundations**: shared color, type, spacing, and radius for web and print
- **Interface**: former design and web design guidelines merged; `/design.md` stays a shorter agent entry point
- **Print**: layout, IBM Plex, page numbers, Pantone, and paper
- **Writing**: punctuation and word-choice rules live here only
- **Agents**: `/llms-full.txt` and public markdown URLs for each topic
- **Site**: Inter on screen; text gold `#8A6300` / `#E8B84A` in dark mode

## 1.x (archived)

Prior versions lived as separate writing (1.0.0), web design (1.1.1), design (1.3.1), and brand (1.0.0) files. Legacy `/guidelines/design/` and `/guidelines/web-design/` pages redirect to Interface.
