    <h1 class="text-4xl font-semibold tracking-tight text-pretty text-gray-900 sm:text-5xl dark:text-white">About Shellui</h1>
    <p class="mt-4 text-lg text-gray-600 dark:text-gray-400">An open source web app development platform.</p>
    <div class="mt-10 text-base/7 text-gray-600 dark:text-gray-400 space-y-4">
      <p>Shellui was born out of frustration. After rebuilding the same authentication flows, admin panels, and boilerplate infrastructure across multiple projects, it became clear that too much time was being spent solving problems that had already been solved before.</p>
      <p>The idea is simple: extract the repetitive parts of web application development into a single, reusable shell - and keep it as straightforward as possible. No over-engineering, no unnecessary abstractions. Just a solid foundation that lets you focus on what actually makes your project unique.</p>
      <p>By making Shellui open source, the hope is that other developers facing the same frustration can benefit from it too - and hopefully make it better along the way.</p>
